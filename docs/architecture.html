01 · Sistema

Arquitectura

Mobile Alert intermedia entre el sistema propio de cada institución (cuartel) y los dispositivos de sus bomberos. No administra las credenciales de los bomberos por defecto: puede delegar la autenticación al backend de la institución.

02 · Caso de uso

Inicio de sesión

La contraseña se valida localmente (BCrypt) o se reenvía al backend propio de la institución, según si esta tiene configurada autenticación delegada.

03 · Caso de uso

Registro de dispositivo

Un token de dispositivo previamente asociado a otro bombero se reasigna automáticamente, cubriendo el caso de un mismo teléfono reutilizado por otra cuenta.

04 · Caso de uso

Creación y envío de una alerta

El envío es parcial por diseño: si algún destinatario es inválido o no tiene dispositivo, la alerta igual se envía a los restantes. El reenvío automático continúa hasta la primera respuesta o el máximo de reintentos configurado.

05 · Caso de uso

Respuesta a una alerta y notificación al cuartel

La primera respuesta registrada detiene los reintentos de envío para el resto de los destinatarios de esa alerta.

06 · Caso de uso

Registro de webhook

La clave de firma se devuelve una única vez, en la respuesta de este llamado.
